Troubleshooting

Common fixes

FLAC file missing, renamed, or moved

Restore the file path, reopen the files, or reopen a SwiftTag document that can resolve bookmarks.

Cannot save due to lock state

Locked tracks are skipped. Select intended tracks and use Toggle Selected Tracks Lock.

Save affected more or fewer tracks than expected

Check General settings for save scope, then verify current table selection.

Album art did not propagate as expected

Check Tags settings for front-cover and all-picture propagation before Save Pictures.

AppleScript automation prompts

macOS may ask for automation permission when another app controls SwiftTag.

Related: Save Changes, AppleScript.
