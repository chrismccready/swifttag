Troubleshooting

Common fixes

FLAC file missing, renamed, or moved

Restore the file path, reopen the files, or reopen a SwiftTag document that can resolve bookmarks.

Cannot save due to lock state

Locked (read-only) tracks are skipped. Select intended tracks and use Toggle Selected Tracks Lock.

Save affected more or fewer tracks than expected

Check General settings for save scope, then verify current table selection.

Album art did not propagate as expected

Check Tags settings Picture Management: Save Front Cover to all Tracks and Save all Pictures to all Tracks before Save Pictures.

AppleScript automation prompts

macOS may ask for automation permission when another app controls SwiftTag.

AppleScript and app sandboxing

Telling SwiftTag to read and write files (FLAC or `.swifttag` documents) through AppleScript may be restricted by macOS app sandboxing. Add permissioned sandbox paths via General settings: SwiftTag Sandbox Paths to give SwiftTag read-write access to specified folders.

Related: Save Changes, AppleScript.
