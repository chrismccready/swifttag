AppleScript record types

These record types define structured AppleScript values used by SwiftTag windows, geometry, and color settings.

point

Suite SwiftTag Suite
Code poin
Description A point value in 2D space.
Property Code Type Description
x xpos integer The x coordinate value.
y ypos integer The y coordinate value.

rectangle

Suite SwiftTag Suite
Code rect
Description A rectangle value in 2D space.
Property Code Type Description
x xpos integer The x coordinate value.
y ypos integer The y coordinate value.
width widt integer The width coordinate value.
height heig integer The height coordinate value.

color

Plural color records
Suite SwiftTag Suite
Code colr
Description A color value in RGBA color space (values 0-1.0).
Property Code Type Description
red redc real The red component value (0-1.0).
green grec real The green component value (0-1.0).
blue bluc real The blue component value (0-1.0).
alpha alph real The alpha component value (0-1.0).

Color Type for track to track diff color, track to file diff color, externally modified diff color, track and disc total mismatch color, picture status overlay color.
See Diff Color Preferences and Diff Formatting for more information.
