AppleScript enumerations

These enumerations define named AppleScript values accepted by SwiftTag commands and settings.

save options

Suite Standard Suite
Code savo
Enumerator Code Description
yes yes Save the file.
no no Do not save the file.
ask ask Ask the user whether or not to save the file.

save scope options

Suite Standard Suite
Code svso
Enumerator Code Description
all altr Save all editable tracks in an editor window.
selected sltr Save selected editable tracks in an editor window.

Options for track save scope and track save payload.
See Scope and Payload and Save Settings for more information.

save payload options

Suite Standard Suite
Code svpo
Enumerator Code Description

pictures only pcos Save editable track pictures in an editor window.
tags and pictures tpos Save editable track tags and pictures in an editor window.

Options for track save scope and track save payload.
See Scope and Payload and Save Settings for more information.

Code ttks
Enumerator Code Description
