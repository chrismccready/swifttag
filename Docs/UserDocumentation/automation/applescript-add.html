AppleScript add command

The add command adds one or more FLAC files to an editor window. It returns the added track or tracks.

Definition

Name add
Suite SwiftTag Suite
Code SwTGaddt
Description Add one or more FLAC files to an editor window.

Targets

Target Behavior
application Adds to the to editor window, or the front editor window when to is omitted.
editor window Adds directly to that editor window.

Parameters

Parameter Code Type Optional Description
direct parameter file or list of file No FLAC files to add.
to insh editor window Yes Editor window that should receive added files.
with lock wlok boolean Yes Whether added tracks should be locked. Default: false.

Result: track or list of track.

Examples

AppleScript
tell application "SwiftTag"
    add POSIX file "/path/to/track.flac" to front editor window with lock false
end tell
AppleScript
tell application "SwiftTag"
    tell front editor window
        set addedTrack to add POSIX file "/path/to/track.flac" with lock true
    end tell
end tell
