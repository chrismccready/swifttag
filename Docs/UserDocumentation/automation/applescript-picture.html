AppleScript picture class

The picture class represents one FLAC picture block on a track. It exposes picture type, description, image data, derived dimensions, and SwiftTag identifiers.

Definition

Name picture
Plural pictures
Suite SwiftTag Suite
Code fpic
Cocoa Class SwiftTagScriptPicture
Description A FLAC track picture.

Access

Pictures are read-write elements of the track class. Use make to create a picture and delete to remove one.

AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        set coverPicture to first picture whose picture type is front cover
        set coverDescription to description of coverPicture
    end tell
end tell

Contents

Type Cocoa Key Description
data data The raw image data in bytes. Accepted as picture data when making or importing a new picture.

Properties

Property Code Type Access Cocoa Key Description
id ID text read-only id The unique identifier of the picture.
pool id poid text read-only poolId The unique SwiftTag picture pool identifier of the picture.
picture type pcty flac picture type read-write pictureType The FLAC track file picture type. Accepted when making or importing a new picture; defaults to front cover when omitted.
MIME type mime text read-only mimeType The format of the image data. Accepted when making or importing a new picture as a hint, but SwiftTag uses the value derived from image data when it can be determined.
description tdsc text read-write pictureDescription A UTF-8 text string describing the image. Accepted when making or importing a new picture.
width widt integer or missing value read-only width The image width dimension in pixels. SwiftTag derives this value from image data when making or importing a picture.
height heig integer or missing value read-only height The image height dimension in pixels. SwiftTag derives this value from image data when making or importing a picture.
color depth cdpt integer or missing value read-only colorDepth The image color depth in bits per pixel. SwiftTag derives this value from image data when making or importing a picture.
colors cols integer or missing value read-only colors The number of colors for indexed palettes (0 for non-indexed). SwiftTag derives this value from image data when making or importing a picture.
data pcda any read-write data The raw image data in bytes, or a base64 encoded text string when making or updating a picture. Changing it derives MIME type and dimensions from the new data.

Examples

AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        set coverPicture to first picture whose picture type is front cover
        set coverSize to {width of coverPicture, height of coverPicture}
        set description of coverPicture to "Front cover"
    end tell
end tell
AppleScript
use framework "Foundation"
use scripting additions

tell application "SwiftTag"
     tell track 1 of front editor window
        -- create picture from memory (binary/base64-encoded image data) --
        make new picture with properties {data:imageData, picture type:performance, description:"center stage close-up"}

        -- move a picture from one FLAC picture type to another --
        set leafletPicture to first picture whose picture type is leaflet
        set leafletPictureData to data of leafletPicture
        make new picture with data leafletPictureData with properties {picture type:media, description:"Leaflet/Media"}
        log "Moved picture with pool id " & pool id of result & " from leaflet to media with description " & quote & description of result & quote & "."
        delete leafletPicture

        -- create picture from file --
        set pictureFilePath to "/path/to/image.jpg"
        set newLeafletPictureData to my getBase64EncodedData from pictureFilePath
        set newLeafletPicture to make new picture with properties {data:newLeafletPictureData, picture type:leaflet, description:"Leaflet"}
    end tell
end tell

-- Base64 encode file data for AppleScript/NSData friendly binary data handling --
on getBase64EncodedData from filePath
    try
        set fileURL to current application's |NSURL|'s fileURLWithPath:filePath
        set fileData to current application's NSData's dataWithContentsOfURL:fileURL
        if fileData is missing value then
            error "ERROR: Could not read data from file. Check the path."
        end if
        return (fileData's base64EncodedStringWithOptions:0) as text
    on error errorMessage number errorNumber
        error "ERROR: Failed to get byte data. " & errorMessage & " (" & errorNumber & ")"
    end try
end getBase64EncodedData
