AppleScript open command

The open command opens SwiftTag session documents and returns the opened document or documents. Use add to add FLAC files to an editor window.

Definition

Name open
Suite Standard Suite
Code aevtodoc
Description Open a document.

Target

The application class responds to open. SwiftTag accepts .swifttag document files.

Parameters

Parameter Type Optional Description
direct parameter file or list of file No Document files to open.

Result: document or list of document.

Examples

AppleScript
tell application "SwiftTag"
    set sessionDocument to open POSIX file "/path/to/session.swifttag"
end tell
