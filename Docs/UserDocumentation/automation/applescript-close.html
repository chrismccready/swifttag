AppleScript close command

The close command closes a document, editor window, or settings window. Documents and editor windows can use save options before closing.

Definition

Name close
Suite Standard Suite
Code coreclos
Cocoa Class NSCloseCommand
Description Close a document, editor window, or settings window.

Targets

Target Behavior
document Closes document editor. saving yes saves the SwiftTag session document first.
editor window Closes editor window. saving yes saves FLAC metadata first.
settings window Closes settings window.

Parameters

Parameter Code Type Optional Description
direct parameter specifier No Document(s) or window(s) to close.
saving savo save options Yes Whether changes should be saved before closing.
saving in kfil file Yes File in which to save the document.
saving scope svso save scope options Yes Track selection scope for editor-window save before close.
saving payload svpo save payload options Yes Track payload for editor-window save before close.

Save Options

Enumeration Values
save options yes, no, ask
save scope options all, selected
save payload options tags only, pictures only, tags and pictures

Omitted saving defaults to ask. The saving in parameter applies to documents. Editor windows do not support a save destination when saving before close.

Examples

AppleScript
tell application "SwiftTag"
    close document of front editor window saving yes saving in POSIX file "/path/to/session.swifttag"
end tell
AppleScript
tell application "SwiftTag"
    close front editor window saving yes saving scope selected saving payload tags only
end tell
AppleScript
tell application "SwiftTag"
    close front settings window
end tell
