AppleScript window classes

SwiftTag exposes visible windows through the base window class and two concrete subclasses: settings window and editor window.

window

The window class represents a visible application window. It provides common title, ordering, geometry, and window-state properties.

Name window
Plural windows
Suite SwiftTag Suite
Code cwin
Cocoa Class NSWindow
Description A window.

window Properties

Property Code Type Access Description
name pnam text read-only The title of the window.
id ID integer read-only The unique identifier of the window.
index pidx integer read-write The index of the window, ordered front to back.
bounds pbnd rectangle read-write The bounding rectangle of the window.
closeable hclb boolean read-only Does the window have a close button?
collapseable pWSh boolean read-only Does the window have a collapse button?
collapsed wshd boolean read-write Is the window collapsed?
full screen pFSc boolean read-write Is the window full screen?
position ppos point read-write The upper-left position of the window.
resizable prsz boolean read-only Can the window be resized?
visible pvis boolean read-write Is the window visible right now?
zoomable iszm boolean read-only Does the window have a zoom button?
zoomed pzum boolean read-write Is the window zoomed right now?

settings window

The settings window class represents SwiftTag Settings. It inherits all window properties.

Name settings window
Plural settings windows
Suite SwiftTag Suite
Code swin
Inherits window
Cocoa Class SwiftTagScriptSettingsWindow
Description The SwiftTag settings window.

settings window Responds To

Command Cocoa Method Use
close handleCloseScriptCommand: Close the settings window.

editor window

The editor window class represents a SwiftTag editor window. It inherits all window properties and exposes tracks, selection state, modification state, and its session document.

Name editor window
Plural editor windows
Suite SwiftTag Suite
Code edtw
Inherits window
Cocoa Class SwiftTagScriptEditorWindow
Description A SwiftTag editor window.

editor window Elements

Element Access Cocoa Key Use
track read-write tracks Loaded FLAC tracks in the editor window.

editor window Properties

Property Code Type Access Description
document docu document read-only Editor window document.
modified imod boolean read-only Does the editor window contain any modified tracks since last save?
selected tracks selt specifier or track list read-write Currently selected tracks in editor window.
window id ewid text read-only Window UUID.

editor window Responds To

Command Cocoa Method Use
add handleAddTracksScriptCommand: Add FLAC files to the editor window.
save handleSaveScriptCommand: Save the editor window.
close handleCloseScriptCommand: Close the editor window.

Examples

AppleScript
tell application "SwiftTag"
    set frontWindowName to name of front window
    set editorModified to modified of front editor window
end tell
AppleScript
tell application "SwiftTag"
    set settingsWindow to open settings window
    close settingsWindow
end tell
