AppleScript application class

The application class represents SwiftTag itself. It exposes document, window, and track collections, plus read-write settings that mirror SwiftTag Settings.

Definition

Name application
Plural applications
Suite SwiftTag Suite
Code capp
Cocoa Class NSApplication
Description Application program.

Elements

Element Access Cocoa Key Use
document read-write scriptDocuments Open SwiftTag session documents.
window read-only orderedWindows Visible application windows ordered front to back.
settings window read-only scriptSettingsWindows Current SwiftTag settings window, when open.
editor window read-write scriptEditorWindows Open editor windows.
track read-write scriptTracks Loaded FLAC tracks across editor windows.

Properties

Property Code Type Access Description
track save scope svso save scope options read-write Track selection scope of a save operation. Values: all, selected.
track save payload svpo save payload options read-write Track payload of a save operation. Values: tags only, pictures only, tags and pictures.
save referenced document svrd boolean read-write Save the editor window's referenced document after a save operation.
ask to save new document asnd boolean read-write Ask to save a new document after a save operation when no document is associated.
zero pad track numbers zptn boolean read-write Zero-pad track number and total values on save.
zero pad disc numbers zpdn boolean read-write Zero-pad disc number and total values on save.
track total key ttks track total key setting read-write Track total tag key preference. Values: TOTALTRACKS, TRACKTOTAL, TOTALTRACKS and TRACKTOTAL.
disc total key dtks disc total key setting read-write Disc total tag key preference. Values: TOTALDISCS, DISCTOTAL, TOTALDISCS and DISCTOTAL.
auto update track total autt boolean read-write Automatically update track total from the track table count.
apply compilation to all tracks apct boolean read-write Apply compilation setting to all tracks.
save front cover to all tracks sfct boolean read-write Save front cover pictures to all tracks.
save all pictures to all tracks sapt boolean read-write Save all picture records to all tracks.
send save notifications snse save notifications setting read-write Save notification preference. Values: always, when not frontmost, never.
theme thse theme setting read-write App theme preference. Values: light, dark, system.
track to track diff color ttdc color read-write Track-to-track diff color record.
track to file diff color ttfd color read-write Track-to-file diff color record.
externally modified diff color emdc color read-write Externally modified diff color record.
track and disc total mismatch color tddc color read-write Track and disc total mismatch color record.
picture status overlay color psoc color read-write Picture status overlay color record.
format on track to file diff ftfd boolean read-write Perform text formatting on track-to-file diffs.
format on track to track diff fttd boolean read-write Perform text formatting on track-to-track diffs.
format on externally modified diff ftem boolean read-write Perform text formatting on externally modified diffs.
format on track total mismatch fttm boolean read-write Perform text formatting on track total mismatches.
format on disc total mismatch ftdm boolean read-write Perform text formatting on disc total mismatches.
format on duplicate picture fodp boolean read-write Show color overlay on duplicate pictures.

Color properties use records with red, green, blue, and alpha values from 0 to 1.0.

Responds To

Command Cocoa Method Use
add handleAddTracksScriptCommand: Add FLAC files to an editor window.
open handleOpenScriptCommand: Open SwiftTag documents.
open settings window handleOpenSettingsWindowScriptCommand: Open or reveal the settings window.
make handleMakeScriptCommand: Create scriptable objects such as tags and pictures.
quit handleQuitScriptCommand: Quit SwiftTag.

Examples

AppleScript
tell application "SwiftTag"
    set track save scope to selected
    set track save payload to tags only
    set theme to system
end tell
AppleScript
tell application "SwiftTag"
    set loadedTracks to tracks
    open settings window
end tell
