Automation

AppleScript overview

SwiftTag is scriptable through AppleScript. Use scripts to add FLAC files, inspect editor windows, change tracks and tags, import pictures, and save with explicit scope and payload.

Object Model

  • application
  • editor windows and settings windows
  • tracks, tags, pictures, and documents

Core Commands

  • add
  • save
  • make
  • delete
  • import picture
  • open settings window
AppleScript save commands can write FLAC files. Make scope and payload explicit.
AppleScript
tell application "SwiftTag"
    save front editor window with scope selected with payload tags only
end tell
