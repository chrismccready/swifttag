Automation

AppleScript overview

SwiftTag is scriptable through AppleScript. Use scripts to add FLAC files, inspect editor windows, change tracks and tags, create pictures, and save with explicit scope and payload.

Object Model

  • application
  • windows, editor windows, and settings windows
  • tracks, tags, pictures, and documents

Core Commands

  • add
  • open
  • save
  • close
  • make
  • delete
  • open settings window
  • quit
AppleScript save commands can write FLAC files. Make scope and payload explicit.
AppleScript
tell application "SwiftTag"
    save front editor window with scope selected with payload tags only
end tell

Reference: application class, window classes, track class, tag class, picture class, document class, add command, delete command, save command, close command. More scripts: AppleScript Examples.
