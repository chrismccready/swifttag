Automation

AppleScript save command

The save command saves a document or editor window. Documents save SwiftTag session data. Editor windows save FLAC metadata using optional scope and payload overrides.

Definition

Name save
Suite Standard Suite
Code coresave
Description Save a document or editor window.

Targets

Target Behavior
document Saves the SwiftTag session document. The in parameter can choose a destination file.
editor window Saves FLAC metadata for editable tracks. The in parameter is not supported.
Saving an editor window can rewrite source FLAC files. Use explicit with scope and with payload when automating writes.
To clarify a document object specifier inside a tell front editor window block, use save its document in ... or save document of it in ... to save the SwiftTag document.

Parameters

Parameter Code Type Optional Description
direct parameter specifier No Document(s) or window(s) to save.
in kfil file Yes File in which to save the document.
with scope svso save scope options Yes Track selection scope for editor-window FLAC save.
with payload svpo save payload options Yes Track payload for editor-window FLAC save.

Scope And Payload Options

Enumeration Values
save scope options all, selected
save payload options tags only, pictures only, tags and pictures

When scope or payload is omitted, SwiftTag uses current application save settings for the editor window.

Examples

AppleScript
tell application "SwiftTag"
    save document of front editor window in POSIX file "/path/to/session.swifttag"
end tell
AppleScript
tell application "SwiftTag"
    tell front editor window
        save its document in POSIX file "/path/to/session.swifttag"
    end tell
end tell
AppleScript
tell application "SwiftTag"
    save front editor window with scope selected with payload tags only
end tell
