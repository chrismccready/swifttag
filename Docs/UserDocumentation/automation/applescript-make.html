AppleScript make command

The make command creates scriptable objects. SwiftTag uses it for creating track tag and picture objects.

Definition

Name make
Suite Standard Suite
Code corecrel
Cocoa Class SwiftTagCreateCommand
Description Create new object.

Targets

Target Behavior
application Creates a supported object when the insertion location or receiver resolves to a track.
track Creates tag or picture objects in that track.

Parameters

Parameter Code Type Optional Description
new kocl type No Class of new object. SwiftTag supports tag and picture for tracks.
at insh location specifier Yes Location at which to insert the object.
with data data any Yes Initial contents of the object. For pictures, accepted as image data.
with properties prdt record Yes Initial property values.

Result: object specifier for the new object.

Examples

AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        -- Create a new custom tag --
        set newTag to make new tag with properties {key:"TEST", value:"This is a test"}
        
        -- Create a tag that matches a defined track property --
        make new tag with properties {key:"COMMENT", value:"Reviewed"}
        -- Which is the same as --
        set comment to "Reviewed"
    end tell
end tell
AppleScript
tell application "SwiftTag"
    set newWindow to make new editor window
    tell newWindow
        set newWindowBounds to bounds
        set bounds to {x: (x of newWindowBounds) + 100, y: (y of newWindowBounds), width: 1100, height: 900}
    end tell
end tell
AppleScript
use framework "Foundation"
use scripting additions

tell application "SwiftTag"
    tell track 1 of front editor window
        set filePath to "/path/to/image.jpg"
        set imageData to my getBase64EncodedData from filePath
        set newCover to make new picture with properties {data:imageData, picture type:front cover, description:"Cover"}
    end tell
end tell

on getBase64EncodedData from filePath
    set fileURL to current application's |NSURL|'s fileURLWithPath:filePath
    set fileData to current application's NSData's dataWithContentsOfURL:fileURL
    if fileData is missing value then
        error "Could not read data from file."
    end if
    return (fileData's base64EncodedStringWithOptions:0) as text
end getBase64EncodedData
