AppleScript make command

The make command creates scriptable objects. SwiftTag uses it for creating track tag and picture objects.

Definition

Name make
Suite Standard Suite
Code corecrel
Cocoa Class SwiftTagCreateCommand
Description Create new object.

Targets

Target Behavior
application Creates a supported object when the insertion location or receiver resolves to a track.
track Creates tag or picture objects in that track.

Parameters

Parameter Code Type Optional Description
new kocl type No Class of new object. SwiftTag supports tag and picture for tracks.
at insh location specifier Yes Location at which to insert the object.
with data data any Yes Initial contents of the object. For pictures, accepted as image data.
with properties prdt record Yes Initial property values.

Result: object specifier for the new object.

Examples

AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        make new tag at end of tags with properties {key:"COMMENT", value:"Reviewed"}
    end tell
end tell
AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        make new picture at end of pictures with data imageData with properties {picture type:front cover}
    end tell
end tell
