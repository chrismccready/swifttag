AppleScript open settings window command

The open settings window command opens SwiftTag Settings, or brings the existing settings window frontmost.

Definition

Name open settings window
Suite SwiftTag Suite
Code SwTGoswn
Description Open the SwiftTag settings window, or bring it frontmost if it is already open.

Target

The application class responds to open settings window.

Result: settings window.

Examples

AppleScript
tell application "SwiftTag"
    set settingsWindow to open settings window
end tell
