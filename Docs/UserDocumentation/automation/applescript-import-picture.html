AppleScript import picture command

The import picture command imports image data as a track picture. SwiftTag validates the image data, derives image dimensions, and prefers the MIME type derived from the image data.

Definition

Name import picture
Suite SwiftTag Suite
Code SwTGimpt
Cocoa Class SwiftTagImportPictureCommand
Description Import image data as a track picture.

Targets

Target Behavior
application Imports into a track resolved from the command receiver or direct object.
track Imports the picture into that track.

Parameters

Parameter Code Type Optional Description
direct parameter any Yes Image data to import.
with data pdat any Yes Image data to import.
with picture type pcty flac picture type Yes FLAC picture type. Defaults to front cover.
with description tdsc text Yes Picture description. If omitted, SwiftTag preserves a duplicate description or uses the default for the picture type.
with MIME type mime text Yes Optional MIME type hint.

Result: picture.

Examples

AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        import picture with data imageData with picture type front cover with description "Cover"
    end tell
end tell
