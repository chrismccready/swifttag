AppleScript document class

The document class represents a SwiftTag session document. It exposes read-only document identity and save state, and it can be saved or closed by AppleScript.

Definition

Name document
Plural documents
Suite Standard Suite
Code docu
Cocoa Class SwiftTagScriptDocument
Description A SwiftTag document.

Access

Documents are application elements. Editor windows also expose their session document through the read-only document property.

AppleScript
tell application "SwiftTag"
    set sessionDocument to document of front editor window
    set documentName to name of sessionDocument
end tell

Properties

Property Code Type Access Description
file file file read-only Document location on disk, if it has one.
modified imod boolean read-only Whether document has changed since last save.
name pnam text read-only Document display name.

Responds To

Command Use
save Save the SwiftTag session document, optionally to a file.
close Close the document, optionally saving first.

Examples

AppleScript
tell application "SwiftTag"
    set sessionDocument to document of front editor window
    save sessionDocument in POSIX file "/path/to/session.swifttag"
end tell
AppleScript
tell application "SwiftTag"
    close document of front editor window saving yes
end tell
