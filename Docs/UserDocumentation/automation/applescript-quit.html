AppleScript quit command

The quit command quits SwiftTag.

Definition

Name quit
Suite Standard Suite
Code aevtquit
Cocoa Class NSQuitCommand
Description Quit application.

Target

The application class responds to quit.

Examples

AppleScript
tell application "SwiftTag"
    quit
end tell
