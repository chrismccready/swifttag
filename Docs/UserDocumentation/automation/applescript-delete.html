AppleScript delete command

The delete command removes scriptable objects from the current editor state. SwiftTag uses it for tracks, tags, pictures, and track properties backed by FLAC tags.

Definition

Name delete
Suite Standard Suite
Code coredelo
Cocoa Class SwiftTagDeleteCommand
Description Delete object.

Targets

Target Behavior
track Removes the track from its editor window. This does not delete the FLAC file from disk.
tag Deletes the FLAC metadata tag from its track.
picture Deletes the FLAC picture from its track.
track property Deletes the corresponding FLAC tag value so the property becomes missing value.

Parameters

Parameter Code Type Optional Description
direct parameter specifier No Object or objects to delete.

Result: none.

Examples

AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        delete comment
        delete first tag whose key is "ALBUM"
    end tell
end tell
AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        delete first picture whose picture type is front cover
        delete every picture whose description is "delete me"
    end tell
end tell
AppleScript
tell application "SwiftTag"
    tell front editor window
        delete every track whose title is "Scratch Take"
    end tell
end tell
