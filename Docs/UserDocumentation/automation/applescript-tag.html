AppleScript tag class

The tag class represents one FLAC metadata key/value pair on a track. Use tags for custom metadata keys and for direct access to stored FLAC tag values.

Definition

Name tag
Plural tags
Suite SwiftTag Suite
Code ftag
Cocoa Class SwiftTagScriptTag
Description A FLAC track metadata tag.

Access

Tags are read-write elements of the track class. Use make to create a tag and delete to remove one.

AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        set albumTag to first tag whose key is "ALBUM"
        set albumName to value of albumTag
    end tell
end tell

Properties

Property Code Type Access Cocoa Key Description
id ID text read-only id The unique identifier of the tag, equal to its normalized key.
key pkey text read-write key A FLAC track metadata tag name.
value pval text read-write value The value associated with a FLAC track metadata key.

Examples

AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        set newTag to make new tag with properties {key:"TEST", value:"This is a test"}
        set value of newTag to "Reviewed"
    end tell
end tell
AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        set artistTag to first tag whose key is "ARTIST"
        delete first tag whose key is "COMMENT"
    end tell
end tell
For convenience, common FLAC metadata keys have been defined as track properties.
