AppleScript track class

The track class represents a loaded FLAC file. It exposes editable FLAC tag fields, read-only audio properties, and child tag and picture objects.

Definition

Name track
Plural tracks
Suite SwiftTag Suite
Code trck
Cocoa Class SwiftTagScriptTrack
Description A FLAC track file.

Access

Tracks are elements of the application and editor window classes. Use add to load FLAC files into an editor window.

AppleScript
tell application "SwiftTag"
    set firstTrack to track 1 of front editor window
    set trackTitle to title of firstTrack
end tell

Elements

Element Access Cocoa Key Use
tag read-write tags FLAC metadata tag objects for this track.
picture read-write pictures FLAC picture objects for this track.

Responds To

Command Cocoa Method Use
make handleMakeScriptCommand: Create tag or picture objects in the track.
delete handleDeleteScriptCommand: Delete the track from its editor window.

Examples

AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        set title to "New Title"
        set track number to 1
        set locked to false
    end tell
end tell
AppleScript
tell application "SwiftTag"
    tell track 1 of front editor window
        set tagCount to count of tags
        set pictureCount to count of pictures
        set audioHash to FLAC fingerprint
    end tell
end tell
