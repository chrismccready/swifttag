Workflow

Save changes

SwiftTag has separate commands for FLAC metadata writeback and `.swifttag` session documents. Pick the command by what you want changed on disk.

Save Commands

Command Writes
Save Uses FLAC File Save settings for payload and scope. Defaults are Tags & Pictures to All Tracks.
Save Tags Writes tag payload only, using current save scope.
Save Pictures Writes picture payload only, using current save scope.
Save SwiftTag Document... Saves a `.swifttag` session package. It does not by itself rewrite FLAC metadata.

Scope And Payload

Save scope is either Selected Tracks or All Tracks. Selected-track save uses the current table selection. All-track save applies to every loaded, imported, unlocked FLAC track with changes for the chosen payload.

Save payload is Tags, Pictures, or Tags & Pictures. The Save command reads these defaults from General settings. Save Tags and Save Pictures override only the payload; they still use current save scope.

Preserve, Replace, Remove

  • Tag-only save preserves existing FLAC pictures.
  • Picture-only save preserves existing FLAC tags.
  • Tags SwiftTag owns may be replaced or removed when saving tags.
  • Pictures SwiftTag owns may be replaced or removed when saving pictures.
  • Locked tracks are skipped by save commands.
  • Files changed outside SwiftTag may show warning status before save.
Save commands can rewrite source FLAC files. Check status icons, selected tracks, lock state, scope and payload settings and tag/picture propagation settings before saving.

Save Feedback

SwiftTag shows save progress while writing. Feedback settings control save notifications: Always, When Not Frontmost, or Never.
