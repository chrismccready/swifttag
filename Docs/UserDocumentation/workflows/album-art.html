Workflow

Pictures/Album Art

SwiftTag supports all FLAC picture record types. Use the front cover well for quick edits and the Picture Browser for full control over all pictures and metadata. See picture class for AppleScript support.

Front Cover Quick Edit

Double-click the front cover well or drag an image onto it to set Cover (front). The well is disabled while saving and when selected files are not editable.

Picture Browser

Choose View > Show Picture Browser (⌘1) or use the front cover context menu. The browser supports all FLAC picture types:

  • Front Cover
  • Back Cover
  • Leaflet or Liner Notes
  • Media (e.g., CD, Vinyl, or Cassette label)
  • Lead Artist, Lead Performer, or Soloist
  • Artist or Performer
  • Conductor
  • Band or Orchestra
  • Composer
  • Lyricist or Text Writer
  • Recording Studio or location
  • Recording Session
  • Performance
  • Capture from Movie or Video
  • Bright(ly) Colored Fish
  • Illustration
  • Band or Artist Logo
  • Publisher or Studio Logo
  • 32x32 PNG Icon
  • Other Icon
  • Other

Use toolbar controls to import, remove, export, copy, paste, navigate among pictures, pin track pictures, and choose picture scope.

Step-by-step example: Open Picture Browser.

Picture Metadata

Picture records keep type, MIME type, description, dimensions, color depth, color count, and binary data. A picture's description can be edited in the browser via the picture's context menu. Total available space per picture for picture data and metadata, including description, is 16 MiB.

Aside from description, SwiftTag derives picture properties from the selected slot and imported image data. Picture type comes from the browser slot, MIME type is normalized from JPEG or PNG data, and width, height, color depth, and palette color count are calculated from image metadata before FLAC writeback.

Example: Edit Picture Description.

Per-Track Records

Tracks carry their own picture records. Shared album art can also be reused through SwiftTag picture identity.

Example: Pin Pictures To Tracks And Slots.

Propagation Settings

Picture Management settings include Save Front Cover to all Tracks and Save all Pictures to all Tracks. These settings can make one album-level art change write to multiple tracks during picture save.

Picture save can replace or remove picture records for saved tracks. Review save scope and propagation settings before writing pictures.
