Workflow

Manage album art

SwiftTag works with FLAC picture records, not only one display image. Front cover is the fast path; Picture Browser exposes other picture types and record metadata.

Front Cover Quick Edit

Double-click the front cover well or drag an image onto it to set Cover (front). The well is disabled while saving and when selected files are not editable.

Picture Browser

Choose View > Show Picture Browser (⌘1) or use the front cover context menu. The browser supports all FLAC picture types:

  • Front Cover
  • Back Cover
  • Leaflet or Liner Notes
  • Media (e.g., CD, Vinyl, or Cassette label)
  • Lead Artist, Lead Performer, or Soloist
  • Artist or Performer
  • Conductor
  • Band or Orchestra
  • Composer
  • Lyricist or Text Writer
  • Recording Studio or location
  • Recording Session
  • Performance
  • Capture from Movie or Video
  • Bright(ly) Colored Fish
  • Illustration
  • Band or Artist Logo
  • Publisher or Studio Logo
  • 32x32 PNG Icon
  • Other Icon
  • Other

Use toolbar controls to import, remove, export, copy, paste, navigate among pictures, pin track pictures, and choose picture scope.

Picture Metadata

Picture records keep type, MIME type, description, dimensions, color depth, color count, and binary data. A picture's description can be edited in the browser via the picture's context menu.

Per-Track Records

Tracks carry their own picture records. Shared album art can also be reused through SwiftTag picture identity.

Propagation Settings

Tags settings include Save Front Cover to all Tracks and Save all Pictures to all Tracks. These settings can make one album-level art change write to multiple tracks during picture save.

Picture save can replace or remove picture records SwiftTag owns for saved tracks. Review save scope and propagation settings before writing pictures.
