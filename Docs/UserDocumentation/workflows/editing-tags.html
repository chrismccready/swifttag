Workflow

Edit tags

Select tracks first. The editor shows album fields, per-track table values, core tags, and misc tags for current selection.

Album Section

Album and Album Artist sit above the track table. Editing these values updates selected track state. Mixed values are visually marked so you can decide whether to unify them.

Track Table

The table shows status, track number, title, optional duration, filename, and optional fingerprint (FLAC MD5). Edit Title directly in the table. Context menu commands can set track total, toggle selected track locks, reload selected tracks, remove selected tracks, and show or hide optional columns.

Core Tags

Core fields include Number, Total Tracks, Disc, Total Discs, Compilation, Genre, Artist, Composer, Location, Date, and Description. Number fields accept positive integer-style input.

Set Track Total writes the current track count into selected total-track fields. If Auto update Track Total is enabled in Tags settings, SwiftTag manages that total automatically.

Misc Tags

Use plus to add a custom key/value row and minus to delete selected rows. Keys are normalized for FLAC tag writing. Invalid or duplicate keys are marked.

Empty values and deleted rows are different editing actions. Empty values are not written as non-empty FLAC comments during tag save. Deleting a misc row removes that key from the editor state for selected tracks.

Multi-Selection

Selection is the source of truth for batch edits. When selected tracks disagree, SwiftTag marks mixed or differing values. Entering a new value applies it to the selected editable tracks.

Locked tracks block editing and writeback. Unlock only files you intend to change.
