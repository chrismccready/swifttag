Workflow

Tags

SwiftTag supports any/all FLAC/Ogg Vorbis tags. The editor window shows common tag fields as well as a misc section for custom keys. Edit tags directly in the editor or via AppleScript. Track table selection is the source of truth for batch edits. When selected tracks differ, SwiftTag marks mixed or differing values. Entering a new value applies it to the selected editable tracks.

Album Section

SwiftTag does not interfere with individual track tag/picture edits, allowinging for mixed album/collection editing workflows; however, various features/settings have been provided to manage an album centric workflow. For example, the Album and Album Artist fields are located above the track table as they are often shared across tracks and visually noteworthy, particularly for multi-track selection edits. Other album-centric features include:

  • File > Set Track Numbers, Set Track Numbers by Disc, Set Track Total, Set Track Total by Disc, and Set Disc Total menu commands.
  • Auto update Track Total setting to manage total track counts.
  • Auto update Disc Total setting to manage total disc counts.
  • Auto update Compilation setting to manage compilation status.
  • Save Front Cover to all Tracks setting to manage cover art presence.
  • Save all Pictures to all Tracks setting to manage album art presence.
  • Formatting specific tag/picture differences.

Track Table

The table shows status, track number, title, optional duration, filename, and optional fingerprint (FLAC MD5). Edit Title directly in the table. Context menu commands can sort tracks by filename or track number, set track numbers, set track numbers by disc, set track total, set track total by disc, set disc total, toggle selected track locks, reload selected tracks, remove selected tracks, and show or hide optional columns.

Track sort mode is per editor window. Number mode sorts by numeric TRACKNUMBER and then filename. Filename mode sorts by filename and then numeric TRACKNUMBER. The active sort mode controls table display, whole-table track-number commands, and AppleScript track ordering.

Core Tags

Core fields include Number, Total Tracks, Disc, Total Discs, Compilation, Genre, Artist, Composer, Location, Date, and Description. Number fields accept positive integer-style input.

Set Track Numbers writes 1-based TRACKNUMBER values using current visible table order. Set Track Numbers by Disc writes 1-based per-disc TRACKNUMBER values for tracks with valid positive DISCNUMBER values. Locked tracks keep existing values but still occupy their visible position, and invalid or missing disc numbers are left unchanged.

Set Track Total writes the current non-deleted track count into total-track fields. Set Track Total by Disc writes each valid disc number's non-deleted track count and leaves blank, zero, or non-numeric disc numbers unchanged. If Auto update Track Total is enabled in Tags: Track Total and Compilation Management settings, SwiftTag manages that total automatically. Set Disc Total writes the highest valid positive DISCNUMBER value into total-disc fields on non-deleted unlocked tracks. If Auto update Disc Total is enabled, SwiftTag manages that total automatically. Saved FLAC output still follows the Write Disc Total key setting.

Misc Tags

Use plus to add a custom key/value row and minus to delete selected rows. Keys are normalized for FLAC tag writing. Invalid or duplicate keys are marked.

Empty values and deleted rows are different editing actions. Empty values are not written as non-empty FLAC comments during tag save. Deleting a misc row removes that key from the editor state for selected tracks.

Multi-Selection

Selection is the source of truth for batch edits. When selected track values differ, SwiftTag marks/formats mixed or differing values/fields. Entering a new value applies it to the selected editable tracks.

Locked (read-only) tracks block editing and writeback. Unlock only files you intend to change.
Tag save can replace or remove tag records for saved tracks. Review save scope and propagation settings before writing tags.
