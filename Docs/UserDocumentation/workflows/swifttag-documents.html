Workflow

SwiftTag documents

A `.swifttag` document stores a session package: track references, bookmark data where available, edited tag state, picture state, and document metadata.

When To Use

Save a SwiftTag document when you want to return to an editing session later before or after writing FLAC files.

Not FLAC Writeback

Saving a SwiftTag document is separate from Save, Save Tags, and Save Pictures. Use Save Changes to write source FLAC metadata.
