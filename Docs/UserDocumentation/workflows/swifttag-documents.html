Workflow

SwiftTag documents

A .swifttag document stores a session package: track references, bookmark data where available, edited tag state, picture state, and document metadata. See document class for AppleScript support.

Possible Use Cases

  • Save an editing session before/after writing FLAC files. This allows you to return to the session later, review edits and write history, and write more changes (or an Undo) when ready.
  • Keep edits when source FLAC files are unavailable, locked, or not ready for writeback.
  • Save FLAC metadata state for archival or reference. Leverage the file system as an observable database (SwiftTag does support Finder Quick Look) and not sacrifice cross-platform portability (the `.swifttag` document is a basic folder with extension containing a single info.plist (xml) file and associated pictures).

Creating and Saving

  1. Add FLAC files with File > Add FLAC files..., drag files into the track table, or use a read-only import when you want inspection without writeback. See Adding FLAC Files.
  2. Edit tags, misc tags, and album art as needed. See Tags and Pictures/Album Art.
  3. Review track status and lock state before deciding whether FLAC writeback should happen now. See Status And Diffs.
  4. Choose File > Save SwiftTag Document..., then save the package where you want the session document to live.
  5. Reopen it later with File > Open SwiftTag Document.... SwiftTag restores saved tags, pictures, track references, and bookmark data when available.
Save SwiftTag Document as... is available via the shift (⇧) key modifier.
Writeback note. Save SwiftTag Document does not rewrite source FLAC files. Use Save Changes when you are ready to write tags or pictures back to FLAC files.

Settings

General settings control what Save writes to FLAC files and whether Command-S (⌘S) follows a FLAC save by saving the referenced SwiftTag document.

Turn on Save referenced document to update an already-associated .swifttag document after the normal Save command completes. Turn on Ask to save new document to be prompted for a new SwiftTag document when no document is associated yet. See Settings: General.

What Gets Stored

The document stores track references, security-scoped bookmarks when available, edited tags, picture records, picture assets, and document metadata. If source FLAC files move or disappear, use the troubleshooting notes for missing files.
