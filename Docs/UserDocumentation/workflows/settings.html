Workflow

Settings

Settings (SwiftTag > Settings... ⌘;) are grouped into General, Tags, and Feedback tabs.

General

General controls Save payload, Save scope, and whether Command-S (⌘S) also saves referenced SwiftTag documents.

Tags

Tags controls number padding, total-count keys, automatic track total, compilation propagation, and picture propagation. These settings affect FLAC writeback when saving tags, pictures, or both. See Scope And Payload before changing defaults for a large batch.

Value Preferences

  • Zero pad Track Number/Total writes track numbers and total tracks with leading zeros when SwiftTag can read numeric values. Example: track 1 of 12 can write as 01 and 12. Default: on.
  • Zero pad Disc Number/Total applies the same padding behavior to disc number and total discs. Default: on.

Key Preferences

FLAC files in the wild use different total-count tag names. SwiftTag lets you choose which keys to write for track totals and disc totals.

Setting Keys Default
Write Track Total key TOTALTRACKS, TRACKTOTAL, both, or neither. TOTALTRACKS and TRACKTOTAL
Write Disc Total key TOTALDISCS, DISCTOTAL, both, or neither. TOTALDISCS

When no total key is selected, SwiftTag does not write that total-count key. Existing total-count keys can be replaced or removed by tag save if SwiftTag owns the tag payload being written.

Track Total And Compilation Management

  • Auto update Track Total keeps total tracks aligned with the loaded track count and disables manual total-track editing. Default: off.
  • Apply Compilation to all Tracks makes compilation state propagate across the full loaded album instead of only the current selected track edit target. Default: off.

Track and disc total mismatches use Feedback colors and Diff Tools formatting. See Diff Formatting.

Picture Management

  • Save Front Cover to all Tracks writes the current front cover to every saved track when picture payload is saved. Default: off.
  • Save all Pictures to all Tracks writes all current picture records to every saved track when picture payload is saved. Default: off.

Picture propagation can make one album-art edit affect many files. Check Album Art propagation and save scope before using Save Pictures or a Save payload that includes pictures.

Feedback

Feedback controls save notifications, app theme, and difference/status colors.

Diff Color Preferences

The Tag Value Difference Colors group contains these color controls:

  • Track to Track Diff Color
  • Track to File Diff Color
  • Externally Modified Diff Color
  • Track/Disc Total Mismatch Color
  • Picture Status Overlay Color

These colors are used by tag-field diff formatting, mismatch warnings, picture duplicate overlays, and external-change status. See Diff Formatting for recognized diff types and text examples.
