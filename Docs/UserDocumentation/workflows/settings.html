Workflow

Settings

Settings (SwiftTag > Settings... ⌘;) are grouped into General, Tags, and Feedback tabs.

General

General controls Save payload, Save scope, and whether Command-S (⌘S) also saves referenced SwiftTag documents.

Tags

Tags controls number padding, total-count keys, automatic track total, compilation propagation, and picture propagation.

Feedback

Feedback controls save notifications, app theme, and difference/status colors.

Diff Color Preferences

The Tag Value Difference Colors group contains these color controls:

  • Track to Track Diff Color
  • Track to File Diff Color
  • Externally Modified Diff Color
  • Track/Disc Total Mismatch Color
  • Picture Status Overlay Color

These colors are used by tag-field diff formatting, mismatch warnings, picture duplicate overlays, and external-change status. See Diff Formatting for recognized diff types and text examples.
