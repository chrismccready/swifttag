Workflow

Settings

Settings (SwiftTag > Settings... ⌘,) are grouped into General, Tags, and Feedback tabs.

General

General controls Command-S (⌘S) save behavior for FLAC files and SwiftTag documents. See Save Scope and Payload before changing defaults for batch saves.

Setting Behavior Default AppleScript
FLAC File Save (⌘S): Write Chooses whether the default save command writes tags, pictures, or both. Tags & Pictures track save payload
FLAC File Save (⌘S): To Chooses whether the default save command writes all loaded tracks or only selected tracks. All Tracks track save scope
Save referenced document Saves the current editor window's referenced SwiftTag document after the default save command. Off save referenced document
Ask to save new document Prompts to save a new SwiftTag document after the default save command when no document is associated yet. Off ask to save new document

SwiftTag Sandbox Paths

SwiftTag Sandbox Paths stores security scoped bookmarked folder paths that the SwiftTag application can reuse when importing FLAC files, saving FLAC changes, or opening/saving SwiftTag documents inside those folders. Under most use cases, like when using the standard open/save panels or drag & drop, SwiftTag can automatically manage access and no additional folder access is needed. Primary use case is with AppleScript where access is not granted through the standard open/save panels, drag & drop, etc. The path list shows stored paths, use the +/- buttons or context menu to manage (including sort).

Tags

Tags controls number padding, total-count keys, automatic track total, compilation propagation, and picture propagation. These settings affect FLAC writeback when saving tags, pictures, or both. See Scope and Payload before changing defaults for a large batch.

Value Preferences

Setting Behavior Default AppleScript
Zero pad Track Number/Total Writes track numbers and total tracks with leading zeros when SwiftTag can read numeric values. Example: track 1 of 12 can write as 01 and 12. On zero pad track numbers
Zero pad Disc Number/Total Applies the same padding behavior to disc number and total discs. On zero pad disc numbers

Key Preferences

FLAC files in the wild use different total-count tag names. SwiftTag lets you choose which keys to write for track totals and disc totals.

Setting Behavior Default AppleScript
Write Track Total key Writes TOTALTRACKS, TRACKTOTAL, both, or neither. TOTALTRACKS and TRACKTOTAL track total key
Write Disc Total key Writes TOTALDISCS, DISCTOTAL, both, or neither. TOTALDISCS disc total key

When no total key is selected, SwiftTag does not write that total-count key. Existing total-count keys can be replaced or removed by tag save if SwiftTag owns the tag payload being written.

Track Total and Compilation Management

Setting Behavior Default AppleScript
Auto update Track Total Keeps total tracks aligned with the loaded track count and disables manual total-track editing. Off auto update track total
Apply Compilation to all Tracks Makes compilation state propagate across the full loaded album instead of only the current selected track edit target. Off apply compilation to all tracks

Track and disc total mismatches use Feedback colors and Diff Tools formatting. See Diff Formatting.

Picture Management

Setting Behavior Default AppleScript
Save Front Cover to all Tracks Writes the current front cover to every saved track when picture payload is saved. Off save front cover to all tracks
Save all Pictures to all Tracks Writes all current picture records to every saved track when picture payload is saved. Off save all pictures to all tracks

Picture propagation can make one album-art edit affect many files. Confirm Save command considering Save scope before using Save Pictures or a Save payload that includes pictures.

Feedback

Feedback controls save notifications, app theme, and visual status cues for differences, mismatches, duplicate pictures, and external changes.

Setting Behavior Default AppleScript
Send Save Notifications Controls whether SwiftTag sends save notifications always, only when not frontmost, or never. When Not Frontmost send save notifications
Theme Controls whether SwiftTag uses light, dark, or system appearance. System theme

Diff Color Preferences

The Tag Value Difference Colors group contains these color controls:

Setting Behavior Default AppleScript
Track to Track Diff Color Colors tag values that differ between loaded tracks. orange track to track diff color
Track to File Diff Color Colors tag values that differ between editor state and source file state. primary track to file diff color
Externally Modified Diff Color Colors tag values when source files changed outside SwiftTag. red externally modified diff color
Track/Disc Total Mismatch Color Colors track-total and disc-total mismatch warnings. red track and disc total mismatch color
Picture Status Overlay Color Colors picture status overlays, including duplicate picture status. orange picture status overlay color

See Diff Formatting for recognized diff types, text examples, enabled settings, and more.
