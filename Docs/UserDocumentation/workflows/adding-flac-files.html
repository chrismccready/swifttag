Workflow

Add FLAC files

SwiftTag imports `.flac` files into the current editor window. Imported files remain referenced source files; saving writes back to those files unless tracks are locked or only a SwiftTag document is saved.

Menu Commands

Command (File >) Shortcut Result
Add FLAC files... ⌘O Adds chosen files to the current track list.
Add FLAC files (replace existing)... ⇧⌘O Replaces the current track list after confirmation when needed.
Add FLAC files (read-only)... ⌥⌘O Adds files locked, so writeback commands skip them.
Add FLAC files (read-only)(replace existing)... ⇧⌥⌘O Replaces current tracks with locked imported tracks.

The file picker accepts FLAC files and folders. When a folder is chosen, SwiftTag imports supported FLAC files it finds for that selection.

Drag And Drop

Drop FLAC files into the track table to add them to the editor. Dropping files appends to the current list and keeps existing imported tracks.

Read-Only Import

Read-only import sets tracks to locked state. Locked tracks can still be inspected, selected, and compared, but metadata fields and save writeback are protected. Use File > Toggle Selected Tracks Lock (⌃L) (or via tracks table context menu) to change selected tracks later.

File Access

SwiftTag keeps source file references and security-scoped access when available. If a file is moved, renamed, deleted, or no longer accessible, status warnings appear and save may fail until the file is available again.
