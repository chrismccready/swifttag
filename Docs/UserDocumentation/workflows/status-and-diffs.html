Status and diffs

Status icons show whether tracks are locked, changed, matching disk, or externally changed.

Icon label Meaning
lock.fill Track is locked.
exclamationmark.triangle File is missing or has external differences.
fish Editor has unsaved differences.
fish.fill Editor matches file.

Use Reload Selected Tracks to refresh source metadata, or Remove Selected Tracks to remove rows from the editor.

Related: Save Changes, Clean Up Album example.
