Examples

Manage Pictures/Album Art

Use this workflow when an album needs front cover art, back cover art, liner notes, or other embedded FLAC picture records. For reference concepts, see Pictures/Album Art overview.

Open Picture Browser

  1. Add FLAC files and select tracks that should receive the art. If no track is selected, Picture Browser works against all loaded tracks.
  2. Choose View > Show Picture Browser (⌘1), or double-click the front cover well.
  3. Use the left list to pick a FLAC picture type/slot, such as Front Cover, Back Cover, Leaflet, Media, Illustration, Band Logo, or Other.

The full slot list and picture-record model are covered in Picture Browser.

Import And Export Pictures

  1. Select the target slot. Example: choose Front Cover for cover art, then Back Cover for a rear scan.
  2. Click Import Picture, click the image well, drag an image onto the image well, or use the context menu command for that slot.
  3. Use Copy and Paste from the image well context menu to reuse picture data between slots.
  4. Click Export Picture or use the context menu to save the current picture out as an image file.

SwiftTag keeps picture type, MIME type, description, dimensions, color depth, color count, and binary data. Export uses the current picture's MIME type when choosing the default file extension.

Edit Picture Description

  1. Select the picture slot and navigate to the picture record.
  2. Open the image well context menu and choose Edit Description....
  3. Review Current Description, enter New Description, then click Done.

Description text must fit inside the FLAC picture block after reserving space for image data, MIME type, fixed FLAC picture fields, and SwiftTag's safety buffer. Total available space for metadata and picture block is 16 MiB. If the new description is too large, SwiftTag blocks the change. More detail: Picture Metadata.

Pin Pictures To Tracks And Slots

The Pin Track Pictures toolbar button pins the current picture for the current slot to the current picture scope. The segmented scope control switches between Selected Track Pictures and All Track Pictures.

  1. Select tracks in the main editor if only some tracks should receive the picture. Leave selection empty, or select all tracks, when the picture belongs to the whole album.
  2. In Picture Browser, choose the slot, such as Front Cover.
  3. Use the scope control to decide whether you are viewing selected-track pictures or all-track pictures.
  4. Turn on Pin Track Pictures to keep the current picture on the editable target tracks for that slot.
  5. To reuse the same image in another slot, switch to that slot, paste or import the image there, then pin that slot too.
Pinning is per slot and per track scope. It does not automatically copy one slot to every other slot. Tags settings can force front-cover or all-picture propagation during picture save.

Related settings: Picture Management. Propagation behavior: Album Art propagation.

Navigate, Remove, And Save

  1. Use First Picture, Previous Picture, Next Picture, and Last Picture when a slot has multiple records.
  2. Use Remove Picture to remove the current picture from the editable target tracks for that slot.
  3. Choose Save Pictures when only embedded images changed, or Save when current General settings include picture payload.

Save behavior reference: Preserve, Replace, Remove.
