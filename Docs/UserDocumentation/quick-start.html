Quick Start

Basic SwiftTag workflow

This workflow is a quick start to the most common SwiftTag features. It is not a comprehensive guide to all features, but it should give you a sense of how SwiftTag works. Essentially: add FLAC files, edit tags and pictures, and save changes.

  1. Open SwiftTag. A new editor window is ready for files.
  2. Choose File > Add FLAC files..., or drag FLAC files into the track table. See Adding FLAC Files for optional replace and read-only (locked) usage.
  3. Select one or more tracks in the table. Track selection controls track-level edits and potentially save scope. See Saving: Scope and Payload.
  4. Edit FLAC track tags: Album, Album Artist, Title, Number, Disc, Genre, Artist, etc. Edits apply to selected tracks. See Edit Tags and Settings: Tags.
  5. Edit FLAC track album art: Front Cover, Back Cover, Leaflet, etc. Double-click the front cover well, drag an image onto it (for default Front Cover), or choose Show Picture Browser for all picture records. See Manage Album Art and Settings: Tags.
  6. Review the status before saving. The track table status icon column (leftmost) shows a solid fish when a track is not modified, an outlined fish when a track is modified, and a lock when a track is read-only (See Read-only Import). Additional status information is made available through field control and value formatting. See Status And Diffs.
  7. Choose a save command. Save uses General settings. Save Tags writes tag changes only. Save Pictures writes picture changes only. Save SwiftTag Document... saves a session package, not FLAC metadata. See Save Changes and SwiftTag Documents.
  8. Confirm save feedback. SwiftTag shows save progress and can send notifications according to Feedback settings.
  9. Continue with Examples, Settings, AppleScript, or Troubleshooting.
Writeback warning. Save, Save Tags, and Save Pictures can rewrite source FLAC files. Locked tracks are skipped. Save SwiftTag Document stores session data and references separately.
