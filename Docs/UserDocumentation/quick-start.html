Quick Start

Basic SwiftTag workflow

This workflow is a quick start to the most common SwiftTag features. It is not a comprehensive guide to all features, but it should give you a sense of how SwiftTag works. Essentially: add FLAC files, edit tags and pictures, and save changes.

  1. Open SwiftTag. A new editor window is ready for files.
  2. Choose File > Add FLAC files..., or drag FLAC files into the track table. See Adding FLAC Files for optional replace and read-only (locked) usage.
  3. Select one or more tracks in the table. Track selection controls track-level edits and potentially save scope. See Saving: Scope and Payload.
  4. Edit Album and Album Artist in the album section. These fields apply through the selected track state.
  5. Edit table titles, Number, Disc, Genre, Artist, Composer, Location, Date, Description, and Misc Tags. See Edit Tags.
  6. Double-click the front cover well, drag an image onto it, or choose Show Picture Browser for full picture records. See Manage Album Art.
  7. Review the status icon column before saving. A lock means writeback is blocked; a warning means SwiftTag saw a missing file or external change. See Status And Diffs.
  8. Choose a save command. Save uses General settings. Save Tags writes tag changes only. Save Pictures writes picture changes only. Save SwiftTag Document... saves a session package, not FLAC metadata. See Save Changes and SwiftTag Documents.
  9. Confirm save feedback. SwiftTag shows save progress and can send notifications according to Feedback settings.
  10. Continue with Examples, Settings, AppleScript, or Troubleshooting.
Writeback warning. Save, Save Tags, and Save Pictures can rewrite source FLAC files. Locked tracks are skipped. Save SwiftTag Document stores session data and references separately.
