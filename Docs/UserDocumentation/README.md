# SwiftTag User Documentation

SwiftTag User Documentation is included in the distributed app bundle and is also available via the 
[SwiftTag GitHub Pages site](https://chrismccready.github.io/swifttag/Docs/UserDocumentation/index.html).
Distributing user documentation in the app bundle itself serves two primary goals:

1. Enable offline access/performance via the actual application installation site.
2. Enable application build validation via embedded 
   [release-information.html](https://chrismccready.github.io/swifttag/Docs/UserDocumentation/release-information.html).

See SwiftTag project [Release Notes](https://github.com/chrismccready/swifttag/releases) to get latest feature and documentation updates.
