SwiftTag Release Information

SwiftTag release notes are available at GitHub SwiftTag Releases.

SwiftTag is an open source app and free to use. All code is available on my public GitHub repository for SwiftTag and the app released from this repository is built by me, Christopher McCready, signed with my Apple Developer ID and notarized by Apple. To confirm authenticity, the following checks can be performed via Terminal on the downloaded app bundle.

codesign

Use codesign (available if Xcode or Command Line Tools are installed) to check the app's signature:

codesign -dv --verbose=2 /path/to/SwiftTag.app

Look for the following in the output:

  • Authority=Developer ID Application: Christopher McCready (8ATUPCQAZN)
  • Authority=Developer ID Certification Authority
  • Authority=Apple Root CA

spctl

Use spctl (available on macOS regardless of Xcode/Command Line Tools installation) to check the app's notarization status:

spctl -a -t exec -vv /path/to/SwiftTag.app

Look for the following in the output:

  • SwiftTag.app: accepted
  • source=Notarized Developer ID
  • origin=Developer ID Application: Christopher McCready (8ATUPCQAZN)
