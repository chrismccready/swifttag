26

27

28

            <section aria-labelledby="access">


66
                <h2 id="access">Access</h2>


67
                <p>


68
                    Tracks are elements of the <a href="applescript-application.html">application</a>


69
                    and <a href="applescript-windows.html#editor-window-definition">editor window</a>


70
                    classes. Use <a href="applescript-add.html"><code>add</code></a> to load FLAC


71
                    files into an editor window.


72
                </p>


73
                <div class="code-label">AppleScript</div>


74
                <pre><code>tell application "SwiftTag"


75
    set firstTrack to track 1 of front editor window


76
    set trackTitle to title of firstTrack


77
    set albumTracks to every track of front editor window whose album is "Test Album"


78
    tell first track of front editor window


79
        log "File path of first track: " & its file


80
    end tell


81
end tell</code></pre>


82
                <aside class="callout note">


83
                    To clarify a <code>file</code> object specifier inside a <code>tell track</code> block, use


84
                    <code>its track</code> or <code>track of it</code> to refer to the <code>track's file</code>.


85
                </aside>
