            <h1>Settings</h1>


26
            <p>


27
                Settings (SwiftTag &gt; Settings... ⌘,) are grouped into <strong>General</strong>, <strong>Tags</strong>, and <strong>Feedback</strong> tabs.


28
                See AppleScript <a href="../automation/applescript-application.html#properties">application class properties</a> for scriptable settings.


29
            </p>

            <h3 id="general-sandbox-paths">SwiftTag Sandbox Paths</h3>


74
            <p>


75
                SwiftTag Sandbox Paths stores security scoped bookmarked folder paths that 


76
                the SwiftTag application can reuse when importing FLAC files, saving FLAC 


77
                changes, or opening/saving SwiftTag documents inside those folders. Under


78
                most use cases, like when using the standard open/save panels or drag & drop,


79
                SwiftTag can automatically manage access and no additional folder access is 


80
                needed. Primary use case is with AppleScript where access is not granted through


81
                the standard open/save panels, drag & drop, etc. The path list shows stored paths,


82
                use the <code>+</code>/<code>-</code> buttons or context menu to manage (including


83
                sort).


84
            </p>


85
            <h2 id="tags">Tags</h2>


86
            <p>


87
                Tags controls number padding, total-count keys, automatic track total,


88
                compilation propagation, and picture propagation. These settings affect


89
                FLAC writeback when saving tags, pictures, or both. See


90
                <a href="saving.html#scope-payload">Scope and Payload</a> before changing


91
                defaults for a large batch.


92
            </p>

            <h3 id="tags-key-preferences">Key Preferences</h3>


124
            <p>


125
                FLAC files in the wild use different total-count tag names. SwiftTag lets


126
                you choose which keys to write for track totals and disc totals.


127
            </p>


128
            <table>


129
                <thead>


130
                    <tr>


131
                        <th>Setting</th>


132
                        <th>Behavior</th>


133
                        <th>Default</th>


134
                        <th>AppleScript</th>


135
                    </tr>


136
                </thead>


137
                <tbody>


138
                    <tr>


139
                        <td><strong>Write Track Total key</strong></td>


140
                        <td>Writes <code>TOTALTRACKS</code>, <code>TRACKTOTAL</code>, both, or neither.</td>


141
                        <td><code>TOTALTRACKS</code> and <code>TRACKTOTAL</code></td>


142
                        <td><a href="../automation/applescript-application.html#property-track-total-key"><code>track total key</code></a></td>


143
                    </tr>


144
                    <tr>


145
                        <td><strong>Write Disc Total key</strong></td>


146
                        <td>Writes <code>TOTALDISCS</code>, <code>DISCTOTAL</code>, both, or neither.</td>


147
                        <td><code>TOTALDISCS</code></td>


148
                        <td><a href="../automation/applescript-application.html#property-disc-total-key"><code>disc total key</code></a></td>


149
                    </tr>


150
                </tbody>


151
            </table>


152
            <p>


153
                When no total key is selected, SwiftTag does not write that total-count key.


154
                Existing total-count keys can be replaced or removed by tag save if SwiftTag


155
                owns the tag payload being written.


156
            </p>
