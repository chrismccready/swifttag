25
            <h1>SwiftTag documents</h1>


26
            <p>


27
                A <code>.swifttag</code> document stores a session package: track references,


28
                bookmark data where available, edited tag state, picture state, and document


29
                metadata. See <a href="../automation/applescript-document.html">document class</a> 


30
                for AppleScript support.


31
            </p>


32
            <h2 id="when-to-use">Possible Use Cases</h2>


33
            <ul>


34
                <li>


35
                    Save an editing session before/after writing FLAC files. This allows you to return to the session later, 


36
                    review edits and write history, and write more changes (or an <strong>Undo</strong>) when ready.


37
                </li>


38
                <li>


39
                    Keep edits when source FLAC files are unavailable, locked, or not ready for


40
                    writeback.


41
                </li>


42
                <li>


43
                    Save FLAC metadata state for archival or reference. Leverage the file system as an observable database (SwiftTag 


44
                    does support Finder Quick Look) and not sacrifice cross-platform portability (the `.swifttag` document is a basic 


45
                    folder with extension containing a single info.plist (xml) file and associated pictures).


46
                </li>


47
            </ul>


48


49
            <h2 id="creating-saving">Creating and Saving</h2>


50
            <ol>


51
                <li>


52
                    Add FLAC files with <strong>File &gt; Add FLAC files...</strong>, drag files


53
                    into the track table, or use a read-only import when you want inspection


54
                    without writeback. See <a href="adding-flac-files.html">Adding FLAC Files</a>.


55
                </li>


56
                <li>


57
                    Edit tags, misc tags, and album art as needed. See


58
                    <a href="tags.html">Tags</a> and


59
                    <a href="pictures.html">Pictures/Album Art</a>.


60
                </li>


61
                <li>


62
                    Review track status and lock state before deciding whether FLAC writeback


63
                    should happen now. See <a href="status-and-diffs.html">Status And Diffs</a>.


64
                </li>


65
                <li>


66
                    Choose <strong>File &gt; Save SwiftTag Document...</strong>, then save the 


67
                    package where you want the session document to live.


68
                </li>


69
                <li>


70
                    Reopen it later with <strong>File &gt; Open SwiftTag Document...</strong>.


71
                    SwiftTag restores saved tags, pictures, track references, and bookmark data


72
                    when available.


73
                </li>


74
            </ol>


75
            <aside class="callout note">


76
                <strong>Save SwiftTag Document as...</strong> is available via the 


77
                <code>shift</code> (<kbd>&#x21E7;</kbd>) key modifier.


78
            </aside>


79
            <aside class="callout warning">


80
                <strong>Writeback note.</strong> Save SwiftTag Document does not rewrite source


81
                FLAC files. Use <a href="saving.html">Save Changes</a> when you are


82
                ready to write tags or pictures back to FLAC files.


83
            </aside>


84


85
            <h2 id="settings">Settings</h2>


86
            <p>


87
                <a href="settings.html#general">General</a> settings control what


88
                <strong>Save</strong> writes to FLAC files and whether Command-S (⌘S) follows a


89
                FLAC save by saving the referenced SwiftTag document.


90
            </p>


91
            <p>


92
                Turn on <strong>Save referenced document</strong> to update an already-associated


93
                <code>.swifttag</code> document after the normal Save command completes. Turn on


94
                <strong>Ask to save new document</strong> to be prompted for a new SwiftTag


95
                document when no document is associated yet. See


96
                <a href="settings.html#general">Settings: General</a>.


97
            </p>


98


99
            <h2 id="stored-data">What Gets Stored</h2>


100
            <p>


101
                The document stores track references, security-scoped bookmarks when available,


102
                edited tags, picture records, picture assets, and document metadata. If source


103
                FLAC files move or disappear, use the troubleshooting notes for


104
                <a href="../troubleshooting.html#missing-files">missing files</a>.


105
            </p>
