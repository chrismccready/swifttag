            <h1>AppleScript tag class</h1>


26
            <p>


27
                The <code>tag</code> class represents one FLAC metadata key/value pair


28
                on a <a href="applescript-track.html"><code>track</code></a>. Use tags


29
                for custom metadata keys and for direct access to stored FLAC tag values.


30

                <h2 id="access">Access</h2>


66
                <p>


67
                    Tags are read-write elements of the <a href="applescript-track.html"><code>track</code></a>


68
                    class. Use <a href="applescript-make.html"><code>make</code></a> to create


69
                    a tag and <a href="applescript-delete.html"><code>delete</code></a> to remove one.


70
                </p>


71
                <div class="code-label">AppleScript</div>


72
                <pre><code>tell application "SwiftTag"


73
    tell track 1 of front editor window


74
        set albumTag to first tag whose key is "ALBUM"


75
        set albumName to value of albumTag


76
    end tell


77
end tell</code></pre>
