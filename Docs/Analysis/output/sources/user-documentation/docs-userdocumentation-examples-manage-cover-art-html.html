            <p class="section-label">Examples</p>
24
            <h1>Manage Pictures/Album Art</h1>
25
            <p>
26
                Use this workflow when an album needs front cover art, back cover art, liner notes,
27
                or other embedded FLAC picture records. For reference concepts, see
28
                <a href="../workflows/pictures.html">Pictures/Album Art</a> overview.
29
            </p>
30


31
            <section aria-labelledby="open-browser">


32
                <h2 id="open-browser">Open Picture Browser</h2>


33
                <ol>


34
                    <li>


35
                        Add FLAC files and select tracks that should receive the art. If no track is


36
                        selected, Picture Browser works against all loaded tracks.


37
                    </li>


38
                    <li>


39
                        Choose <strong>View</strong> &gt; <strong>Show Picture Browser</strong> (⌘1),


40
                        or double-click the front cover well.


41
                    </li>


42
                    <li>


43
                        Use the left list to pick a FLAC picture type/slot, such as


44
                        <strong>Front Cover</strong>, <strong>Back Cover</strong>,


45
                        <strong>Leaflet</strong>, <strong>Media</strong>, <strong>Illustration</strong>,


46
                        <strong>Band Logo</strong>, or <strong>Other</strong>.


47
                    </li>


48
                </ol>


49
                <p>


50
                    The full slot list and picture-record model are covered in


51
                    <a href="../workflows/pictures.html#picture-browser">Picture Browser</a>.


52
                </p>


53
            </section>


54


55
            <section aria-labelledby="import-export">


56
                <h2 id="import-export">Import And Export Pictures</h2>


57
                <ol>


58
                    <li>


59
                        Select the target slot. Example: choose <strong>Front Cover</strong> for


60
                        cover art, then <strong>Back Cover</strong> for a rear scan.


61
                    </li>


62
                    <li>


63
                        Click <strong>Import Picture</strong>, click the image well, drag an image


64
                        onto the image well, or use the context menu command for that slot.


65
                    </li>


66
                    <li>


67
                        Use <strong>Copy</strong> and <strong>Paste</strong> from the image well


68
                        context menu to reuse picture data between slots.


69
                    </li>


70
                    <li>


71
                        Click <strong>Export Picture</strong> or use the context menu to save the


72
                        current picture out as an image file.


73
                    </li>


74
                </ol>


75
                <p>


76
                    SwiftTag keeps picture type, MIME type, description, dimensions, color depth,


77
                    color count, and binary data. Export uses the current picture's MIME type when


78
                    choosing the default file extension.


79
                </p>


80
            </section>


81


82
            <section aria-labelledby="description">


83
                <h2 id="description">Edit Picture Description</h2>


84
                <ol>


85
                    <li>Select the picture slot and navigate to the picture record.</li>


86
                    <li>Open the image well context menu and choose <strong>Edit Description...</strong>.</li>


87
                    <li>Review <strong>Current Description</strong>, enter <strong>New Description</strong>, then click <strong>Done</strong>.</li>


88
                </ol>


89
                <p>


90
                    Description text must fit inside the FLAC picture block after reserving space


91
                    for image data, MIME type, fixed FLAC picture fields, and SwiftTag's safety


92
                    buffer. Total available space for metadata and picture block is 16 MiB. If the 


93
                    new description is too large, SwiftTag blocks the change.


94
                    More detail: <a href="../workflows/pictures.html#metadata">Picture Metadata</a>.


95
                </p>


96
            </section>


97


98
            <section aria-labelledby="pinning">


99
                <h2 id="pinning">Pin Pictures To Tracks And Slots</h2>


100
                <p>


101
                    The <strong>Pin Track Pictures</strong> toolbar button pins the current picture


102
                    for the current slot to the current picture scope. The segmented scope control


103
                    switches between <strong>Selected Track Pictures</strong> and


104
                    <strong>All Track Pictures</strong>.


105
                </p>


106
                <ol>


107
                    <li>


108
                        Select tracks in the main editor if only some tracks should receive the


109
                        picture. Leave selection empty, or select all tracks, when the picture belongs


110
                        to the whole album.


111
                    </li>


112
                    <li>


113
                        In Picture Browser, choose the slot, such as <strong>Front Cover</strong>.


114
                    </li>


115
                    <li>


116
                        Use the scope control to decide whether you are viewing selected-track


117
                        pictures or all-track pictures.


118
                    </li>


119
                    <li>


120
                        Turn on <strong>Pin Track Pictures</strong> to keep the current picture on


121
                        the editable target tracks for that slot.


122
                    </li>


123
                    <li>


124
                        To reuse the same image in another slot, switch to that slot, paste or import


125
                        the image there, then pin that slot too.


126
                    </li>


127
                </ol>


128
                <aside class="callout">


129
                    Pinning is per slot and per track scope. It does not automatically copy one slot


130
                    to every other slot. Tags settings can force front-cover or all-picture propagation


131
                    during picture save.


132
                </aside>


133
                <p>


134
                    Related settings: <a href="../workflows/settings.html#tags-picture-management">Picture Management</a>.


135
                    Propagation behavior: <a href="../workflows/pictures.html#propagation">Album Art propagation</a>.


136
                </p>


137
            </section>


138


139
            <section aria-labelledby="navigate-remove-save">


140
                <h2 id="navigate-remove-save">Navigate, Remove, And Save</h2>


141
                <ol>


142
                    <li>


143
                        Use <strong>First Picture</strong>, <strong>Previous Picture</strong>,


144
                        <strong>Next Picture</strong>, and <strong>Last Picture</strong> when a slot


145
                        has multiple records.


146
                    </li>


147
                    <li>


148
                        Use <strong>Remove Picture</strong> to remove the current picture from the


149
                        editable target tracks for that slot.


150
                    </li>


151
                    <li>


152
                        Choose <strong>Save Pictures</strong> when only embedded images changed, or


153
                        <strong>Save</strong> when current General settings include picture payload.


154
                    </li>


155
                </ol>


156
                <p>


157
                    Save behavior reference:


158
                    <a href="../workflows/saving.html#preserve-replace-remove">Preserve, Replace, Remove</a>.


159
                </p>


160
            </section>
