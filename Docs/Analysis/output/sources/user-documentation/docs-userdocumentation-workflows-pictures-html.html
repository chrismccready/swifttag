            <h1>Pictures/Album Art</h1>


26
            <p>


27
                SwiftTag supports all FLAC picture record types. Use the front cover well for quick edits 


28
                and the <strong>Picture Browser</strong> for full control over all pictures and metadata. 


29
                See <a href="../automation/applescript-picture.html">picture class</a> for AppleScript support.


30
            </p>


31

33
                <h2 id="front-cover">Front Cover Quick Edit</h2>


34
                <p>


35
                    Double-click the front cover well or drag an image onto it to set


36
                    <strong>Cover (front)</strong>. The well is disabled while saving and when


37
                    selected files are not editable.


38
                </p>

            </section>

            <section aria-labelledby="metadata">


81
                <h2 id="metadata">Picture Metadata</h2>


82
                <p>


83
                    Picture records keep type, MIME type, description, dimensions, color depth,


84
                    color count, and binary data. A picture's description can be edited in the browser


85
                    via the picture's context menu. Total available space per picture for picture data 


86
                    and metadata, including description, is 16 MiB.


87
                </p>


88
                <p>


89
                    Aside from description, SwiftTag derives picture properties from the selected


90
                    slot and imported image data. Picture type comes from the browser slot, MIME type


91
                    is normalized from JPEG or PNG data, and width, height, color depth, and palette


92
                    color count are calculated from image metadata before FLAC writeback.


93
                </p>


94
                <p>


95
                    Example: <a href="../examples/manage-cover-art.html#description">Edit Picture Description</a>.


96
                </p>


97
            </section>


98

100
                <h2 id="per-track">Per-Track Records</h2>


101
                <p>


102
                    Tracks carry their own picture records. Shared album art can also be reused


103
                    through SwiftTag picture identity.


104
                </p>


105
                <p>


106
                    Example: <a href="../examples/manage-cover-art.html#pinning">Pin Pictures To Tracks And Slots</a>.


107
                </p>

            <section aria-labelledby="propagation">


111
                <h2 id="propagation">Propagation Settings</h2>


112
                <p>


113
                    <a href="settings.html#tags-picture-management">Picture Management</a> settings include <strong>Save Front 


114
                    Cover to all Tracks</strong> and <strong>Save all Pictures to all Tracks</strong>. These settings can make one


115
                    album-level art change write to multiple tracks during picture save.


116
                </p>


117

118

119

120

121
