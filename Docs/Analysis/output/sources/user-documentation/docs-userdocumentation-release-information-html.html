            <h1>SwiftTag Release Information</h1>


27
            <p>


28
                SwiftTag release notes are available at <a href="https://github.com/chrismccready/swifttag/releases">GitHub SwiftTag Releases</a>.


29
            </p>


30
            <p>


31
                SwiftTag is an open source app and free to use. All code is available on my public GitHub 


32
                <a href="https://github.com/chrismccready/swifttag">repository for SwiftTag</a> and the app released from this repository is built 


33
                by me, Christopher McCready, signed with my Apple Developer ID and notarized by Apple. To confirm authenticity, the following 


34
                checks can be performed via <b>Terminal</b> on the downloaded app bundle.


35
            </p>


36
            <section aria-labelledby="codesign-check">


37
                <h2 id="codesign-check">codesign</h2>


38
                <p>Use <b>codesign</b> (available if Xcode or Command Line Tools are installed) to check the app's signature:</p>


39
                <pre><code>codesign -dv --verbose=2 /path/to/SwiftTag.app</code></pre>


40
                <p>Look for the following in the output:</p>


41
                <ul>


42
                    <li>Authority=Developer ID Application: Christopher McCready (8ATUPCQAZN)</li>


43
                    <li>Authority=Developer ID Certification Authority</li>


44
                    <li>Authority=Apple Root CA</li>


45
                </ul>


46
            </section>


47
            <section aria-labelledby="spctl-check">


48
                <h2 id="spctl-check">spctl</h2>


49
                <p>Use <b>spctl</b> (available on macOS regardless of Xcode/Command Line Tools installation) to check the app's notarization status:</p>


50
                <pre><code>spctl -a -t exec -vv /path/to/SwiftTag.app</code></pre>


51
                <p>Look for the following in the output:</p>


52
                <ul>


53
                    <li>SwiftTag.app: accepted</li>


54
                    <li>source=Notarized Developer ID</li>


55
                    <li>origin=Developer ID Application: Christopher McCready (8ATUPCQAZN)</li>


56
                </ul>


57
            </section>
