25
            <h1>Tags</h1>


26
            <p>


27
                SwiftTag supports any/all FLAC/Ogg Vorbis tags. The editor window shows common tag 


28
                fields as well as a misc section for custom keys. Edit tags directly in the editor 


29
                or via <a href="../automation/applescript-tag.html">AppleScript</a>. Track table selection 


30
                is the source of truth for batch edits. When selected tracks differ, SwiftTag 


31
                <a href="status-and-diffs.html#diff-formatting">marks</a> mixed or differing values. 


32
                Entering a new value applies it to the selected editable tracks.


33
            </p>


34


35
            <section aria-labelledby="album-section">


36
                <h2 id="album-section">Album Section</h2>


37
                <p>


38
                    SwiftTag does not interfere with individual track tag/picture edits, allowinging for 


39
                    mixed album/collection editing workflows; however, various features/settings have been 


40
                    provided to manage an album centric workflow. For example, the <strong>Album</strong> 


41
                    and <strong>Album Artist</strong> fields are located above the track table as they are 


42
                    often shared across tracks and visually noteworthy, particularly for multi-track 


43
                    selection edits. Other album-centric features include:


44
                    <ul>


45
                        <li><strong>File</strong> &gt; <strong>Set Track Numbers</strong>, <strong>Set Track Numbers by Disc</strong>, <strong>Set Track Total</strong>, <strong>Set Track Total by Disc</strong>, <strong>Set Disc Total</strong>, and track file rename menu commands.</li>


46
                        <li><a href="settings.html#tags-track-total-compilation"><strong>Auto update Track Total</strong></a> setting to manage total track counts.</li>


47
                        <li><a href="settings.html#tags-track-total-compilation"><strong>Auto update Disc Total</strong></a> setting to manage total disc counts.</li>


48
                        <li><a href="settings.html#tags-track-total-compilation"><strong>Auto update Compilation</strong></a> setting to manage compilation status.</li>


49
                        <li><a href="settings.html#tags-picture-management"><strong>Save Front Cover to all Tracks</strong></a> setting to manage cover art presence.</li>


50
                        <li><a href="settings.html#tags-picture-management"><strong>Save all Pictures to all Tracks</strong></a> setting to manage album art presence.</li>


51
                        <li><a href="status-and-diffs.html#diff-formatting">Formatting</a> specific tag/picture differences.</li>


52
                    </ul>


53
                </p>


54
            </section>


55


56
            <section aria-labelledby="track-table">


57
                <h2 id="track-table">Track Table</h2>


58
                <p>


59
                    The table shows <a href="status-and-diffs.html">status</a>, track number, title, 


60
                    optional duration, filename, and optional fingerprint (FLAC MD5). Edit <strong>Title</strong> 


61
                    directly in the table. Context menu commands can sort tracks by filename or track number,


62
                    set track numbers, set track numbers by disc, set track total, set track total by disc,


63
                    set disc total, toggle selected track <a href="adding-flac-files.html#read-only">locks</a>, 


64
                    reload selected tracks, remove selected tracks, and show or hide optional columns.


65
                </p>


66
                <p>


67
                    Track sort mode is per editor window. Number mode sorts by numeric


68
                    <code>TRACKNUMBER</code> and then filename. Filename mode sorts by filename and


69
                    then numeric <code>TRACKNUMBER</code>. The active sort mode controls table display,


70
                    whole-table track-number commands, and AppleScript track ordering.


71
                </p>


72
            </section>


73

            <section aria-labelledby="track-file-rename">


75
                <h2 id="track-file-rename">Track File Rename</h2>


76
                <p>


77
                    <strong>File</strong> &gt; <strong>Rename Track Files</strong> renames loaded,


78
                    unlocked FLAC files in place. <strong>Rename Selected Track Files</strong> uses


79
                    the track table selection. <strong>Rename Track Files Config...</strong> opens


80
                    the rename sheet with a live example from the first selected track, or the first


81
                    loaded track when nothing is selected.


82
                </p>


83
                <p>


84
                    <b>Rename formats</b> use tag placeholders wrapped in pipes, for example


85
                    <code>|TRACKNUMBER| |TITLE|</code>. Placeholder matching accepts common aliases


86
                    such as <code>|track number|</code> and <code>|number|</code>. Prepend 


87
                    <code>zp</code> to zero-pad numeric values, for example 


88
                    <code>|zpTRACKNUMBER|</code>, <code>|zpDISCNUMBER|</code>, 


89
                    <code>|zpTOTALTRACKS|</code>, or <code>|zpTOTALDISCS|</code>.


90
                </p>


91
                <p>


92
                    <b>Invalid Replacement</b> chooses how invalid filename characters are replaced


93
                    with: <code>-</code>, <code>_</code>, <code>.</code>, or space. Non-strict mode


94
                    replaces <code>/</code>, <code>:</code>, and NUL. Strict mode also replaces


95
                    <code>&lt;</code>, <code>&gt;</code>, <code>&quot;</code>, <code>\</code>,


96
                    <code>|</code>, <code>?</code>, <code>*</code>, and ASCII control characters.


97
                    <b>Space Replacement</b> can then replace whitespace in the generated filename with


98
                    <code>-</code>, <code>_</code>, or <code>.</code>; choose <b>none</b> to preserve


99
                    whitespace. SwiftTag preserves the original <code>.flac</code> extension.


100
                </p>


101
                <aside class="callout note">


102
                    <code>TOTALTRACKS</code> and <code>TRACKTOTAL</code> are aliases for the same 


103
                    tag, as are <code>TOTALDISCS</code> and <code>DISCTOTAL</code>.


104
                </aside>


105
            </section>

            <section aria-labelledby="core-tags">


108
                <h2 id="core-tags">Core Tags</h2>


109
                <p>


110
                    Core fields include <strong>Number</strong>, <strong>Total Tracks</strong>,


111
                    <strong>Disc</strong>, <strong>Total Discs</strong>, <strong>Compilation</strong>,


112
                    <strong>Genre</strong>, <strong>Artist</strong>, <strong>Composer</strong>,


113
                    <strong>Location</strong>, <strong>Date</strong>, and <strong>Description</strong>.


114
                    Number fields accept positive integer-style input.


115
                </p>


116
                <p>


117
                    <strong>Set Track Numbers</strong> writes 1-based <code>TRACKNUMBER</code> values


118
                    using current visible table order. <strong>Set Track Numbers by Disc</strong> writes


119
                    1-based per-disc <code>TRACKNUMBER</code> values for tracks with valid positive


120
                    <code>DISCNUMBER</code> values. Locked tracks keep existing values but still occupy


121
                    their visible position, and invalid or missing disc numbers are left unchanged.


122
                </p>


123
                <p>


124
                    <strong>Set Track Total</strong> writes the current non-deleted track count into


125
                    total-track fields. <strong>Set Track Total by Disc</strong> writes each valid


126
                    disc number's non-deleted track count and leaves blank, zero, or non-numeric


127
                    disc numbers unchanged. If <strong>Auto update Track Total</strong> is enabled in


128
                    <a href="settings.html#tags-track-total-compilation">Tags: Track Total and Compilation Management</a> 


129
                    settings, SwiftTag manages that total automatically.


130
                    <strong>Set Disc Total</strong> writes the highest valid positive


131
                    <code>DISCNUMBER</code> value into total-disc fields on non-deleted unlocked


132
                    tracks. If <strong>Auto update Disc Total</strong> is enabled, SwiftTag manages


133
                    that total automatically. Saved FLAC output still follows the


134
                    <strong>Write Disc Total key</strong> setting.


135
                </p>


136
            </section>

            <section aria-labelledby="misc-tags">


139
                <h2 id="misc-tags">Misc Tags</h2>


140
                <p>


141
                    Use <code>+</code> to add a custom key/value row and <code>-</code> to delete selected rows.


142
                    Keys are normalized for FLAC tag writing. Invalid or duplicate keys are marked.


143
                </p>


144
                <p>


145
                    Empty values and deleted rows are different editing actions. Empty values are


146
                    not written as non-empty FLAC comments during tag save. Deleting a misc row


147
                    removes that key from the editor state for selected tracks.


148
                </p>


149
            </section>


150


151
            <section aria-labelledby="multi-selection">


152
                <h2 id="multi-selection">Multi-Selection</h2>


153
                <p>


154
                    Selection is the source of truth for batch edits. When selected track values differ,


155
                    SwiftTag <a href="status-and-diffs.html#diff-formatting">marks/formats</a> mixed or 


156
                    differing values/fields. Entering a new value applies it to the selected editable tracks.


157
                </p>


158
                <aside class="callout note">


159
                    Locked (<a href="adding-flac-files.html#read-only">read-only</a>) tracks block editing and


160
                    writeback. Unlock only files you intend to change.


161
                </aside>


162
                <aside class="callout warning">


163
                    Tag save can replace or remove tag records for saved tracks.


164
                    Review <a href="settings.html#general">save scope</a> and 


165
                    <a href="settings.html#tags">propagation</a> settings before writing tags.


166
                </aside>
