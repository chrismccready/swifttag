fix(package): compute accurate image depth and palette colors for SwiftTag export

Body

- Updated `PictureDataUtilities` to compute `depth` and `colors` accurately from original bytes instead of from `32 bpp` decoded memory surfaces.
- Replaced blind `CGImage.bitsPerPixel` reads with direct PNG chunk parsing and prioritized CGImage properties for JPEG files. This correction ensures that `24 bpp` JPEG imagery and indexed-color `8 bpp` PNG imagery will export correct specifications to SwiftTag documents rather than inaccurately reporting `32 bpp` decoded dimensions and zero palettes.
- Included tests for indexed PNG palette count generation, JPEG `24 bpp` fallback reads, and RGBA PNG `32 bpp` detection.
